# **App Name**: Pixel Quest Folio

## Core Features:

- RPG Hero Dashboard: A high-fidelity landing dashboard featuring an RPG character stat card that dynamically updates project counts, total experience months, and skill levels.
- Skill Card Deck: A deck-based skill display using playing card layouts (Kings, Queens, Jokers) with random shuffle animations and hover tilts.
- Career Level System: An interactive vertical progression track that visualizes work history as 'game levels' with XP checkpoints and 8-bit badges.
- Quest Log Archives: A sharp-cornered grid display for developer projects styled as mission logs with status badges and pixel-border effects.
- AI Achievement Oracle: A feature where the LLM acts as a 'Game Narrator' tool to provide personalized feedback or flavor-text summaries of project milestones in various 16-bit persona voices.
- HUD Navigation Interface: A fixed Heads-Up Display navbar featuring a section tracker and a CSS pixel-art avatar of the site owner.
- Konami Unlocker: An interaction feature triggered by key inputs that rewards the user with hidden site modes or specialized pixel badges.

## Style Guidelines:

- The design utilizes a high-contrast dark scheme centered around a Primary Orange (#E05A1E). The background is a deep charcoal (#0A0A0A) which allows for a moody atmospheric layer featuring a muted Reddish-Brown (#2A0F00) city skyline silhouette.
- Accent colors include a vibrant Saturated Orange (#FF6A2E) for hover states and interactive elements, providing a consistent neon glow against the dark voids.
- The font 'Press Start 2P' is recommended for all headings, labels, and dashboard metrics to enforce the retro aesthetic. 'Courier Prime' is suggested for all body descriptions and terminal-style stats. Note: currently only Google Fonts are supported.
- Iconography consists of customized 8-bit CSS pixel art, specifically for skill categories and achievement trophies, using sharp rectangular forms instead of curves.
- Layout structures follow a geometric grid with zero border-radius, featuring dash-lined separators and distinct card containers with visible offset shadows for a chunky, pixelated depth.
- Key interactions use Framer Motion for CRT-style glitches on headers, fan-out animations for playing cards, and smooth scroll progress pulses on the experience track.
